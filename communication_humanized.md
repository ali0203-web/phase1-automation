## 🎨 PRINCIPLES FOR ALL COMMUNICATION

✅ DO:
- Start personal ("I spent 14 weeks..." / "Real talk...")
- Be honest about limitations
- Show you've experienced the problem
- Explain the WHY, not just WHAT
- Use real language (contractions, informal)
- Show vulnerability (mistakes, learning)
- Make it about them, not you
- Include specifics (numbers, examples)

❌ DON'T:
- Use corporate buzzwords (synergy, leverage, etc.)
- Make promises you can't keep
- Sound robotic or templated
- Ignore the human on the other side
- Oversell or use hype
- Be impersonal or formal
- Generic responses
- Use stock phrases

## 📋 TEMPLATE CHECKLIST

Before sending ANY message to people:
□ Does it sound like a real person wrote it?
□ Would I say this in a conversation?
□ Does it explain the WHY?
□ Is there vulnerability or honesty?
□ Could I remove "corporate words"?
□ Does it respect the reader's time?
□ Does it invite connection/response?

If it fails 3+ checks → Rewrite it.
