WHAT IS JEV?
============

Jev is TypeSafe AI's "System One" decision model:
- Fast: 70-500ms response time
- Cheap: $0.042 per million input tokens (output tokens FREE)
- Specialized: Handles 3 decision types only:
  1. Choice (pick from list of options)
  2. Score (rate on a rubric 1-10)
  3. True/False (likelihood estimation)
- Confidence Scoring: Every answer includes confidence number (0.0-1.0)
- Purpose: Gatekeeper for small decisions, leaving Claude for complex work

---

HOW JEV WORKS
=============

1. You describe a situation
2. Jev answers ONE of three question types
3. Jev returns answer + confidence score
4. Your code acts on the answer
5. Anything below confidence threshold → escalate to Claude or human

Example Workflow:
  Task comes in → Jev routing question → "Which model?"
  → If Jev says "fast model" (confidence 0.8+) → use Haiku
  → If Jev says "strongest model" → use Opus
